侧滑抽屉，常用于：用户面板、筛选、快捷菜单、购物车等

区域说明

header：页眉，包含 Logo、导航区域
nav：导航区，内含搜索框 + 菜单链接 + 抽屉触发按钮
hero：首屏横幅，展示站点核心标语
breadcrumb：面包屑导航，页面路径
container：外层布局容器，包裹 sidebar + main
sidebar：固定侧边栏，目录、分类、标签等附属信息
main：语义主内容容器（点击打开抽屉）
content：通用正文内容块
drawer：右侧侧滑抽屉（浮层组件，顶部预留间隙）
footer：页脚，版权、备案、友链
