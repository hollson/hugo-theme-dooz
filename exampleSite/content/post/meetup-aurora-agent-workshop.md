# 主题示例 - 极光紫：AI Agent 实战工作坊（线上直播场）

> **📌 活动信息**
> 🗓 **时间**：2026 年 12 月 6 日（周日）19:30 - 21:30
> 💻 **形式**：线上直播，含 60 分钟实操 + 30 分钟答疑
> 🧰 **准备**：一台能跑 Node.js 的电脑，提前装好编辑器和 API Key
> 🎟 **名额**：300 人，报名后邮件发送直播链接

两个小时的安排很紧：不讲概念史，直接从一份空目录开始，做出一个能跑通「读文件 → 拆任务 → 调工具 → 写回结果」的最小 Agent[^1]。

## 你会带走什么

- 一个可运行的最小 Agent 工程，包含工具注册与结果校验。
- 一套任务拆分的判断标准：什么该交给模型，什么必须写死。
- 一份失败案例清单，知道常见死循环与幻觉是怎么发生的。

## 两小时怎么安排

| 时间 | 内容 | 形式 |
| :--- | :--- | :--- |
| 19:30 - 19:40 | 开场：Agent 的边界 | 讲解 |
| 19:40 - 20:25 | 从零写一个工具调用循环 | 实操 |
| 20:25 - 20:50 | 加约束：状态机与沙箱 | 实操 |
| 20:50 - 21:10 | 现场排错 | 演示 |
| 21:10 - 21:30 | 答疑与延伸阅读 | 互动 |

> [!NOTE] 关于难度
> 默认你会写 JavaScript、用过命令行。不会也没关系，代码会完整给出，照抄能跑。

> [!IMPORTANT] 报名前确认
> 这是一场动手课，不是发布会。只看不练的话，收获会非常有限。

## 适合谁

刚接触 Agent 的后端工程师
: 想知道工具调用到底怎么串起来、失败重试放在哪一层。

正在做内部工具的产品经理
: 想判断哪些流程值得交给 Agent，哪些只是把人工换成更贵的人工。

## 不适合谁

- 期待「一键生成完整产品」的人。
- 只想要 Prompt 模板合集的人。

*工作坊结束后，代码仓库会开放两周，方便你回去继续改。*

[^1]: 示例脚注：报名页的注释一般提示先修条件、退款政策或回放安排。
